# Work Tracker

**Work Tracker** — настольное приложение для преподавателей, предназначенное для просмотра и анализа успеваемости студентов на основе данных из Excel.

Программа предоставляет инструменты для отслеживания успеваемости учебной группы, анализа результатов контрольных работ, учёта пропусков занятий и просмотра подробной информации об отдельных студентах.

## Возможности

- **Успеваемость группы** — просмотр оценок и учебных результатов всех студентов в единой таблице.
- **Карточка студента** — подробная информация об успеваемости и посещаемости каждого студента.
- **Визуализация** — графическое представление учебных результатов группы.
- **Экспорт в PDF** — сохранение карточки студента и диаграмм визуализации в PDF-файл.
- **Контрольные работы** — отслеживание результатов контрольных работ.
- **Учёт посещаемости** — просмотр пропусков занятий и анализ посещаемости.
- **Работа с Excel** — загрузка существующих файлов и создание шаблона для заполнения.
- **Сохранение настроек** — запоминание последнего открытого файла и выбранной темы оформления.
- **Две темы оформления** — светлая и тёмная темы интерфейса.

## Скачать

Актуальная версия программы доступна в разделе [Releases](https://github.com/VladKristoff/WorkTracker/releases/latest).

### Установка

1. Откройте раздел [Releases](https://github.com/VladKristoff/WorkTracker/releases/latest).
2. Скачайте архив `WorkTracker-v1.1.0-windows.zip`.
3. Распакуйте архив в удобную папку.
4. Запустите `WorkTracker.exe`.

Установка Python и дополнительных библиотек для запуска готовой версии не требуется.

При первом запуске необходимые файлы базы данных и настроек создаются автоматически.

> Примечание: если Windows покажет предупреждение SmartScreen, это может быть связано с отсутствием цифровой подписи исполняемого файла.

## Работа с программой

1. На главном экране загрузите готовый Excel-файл (`.xlsx`) или создайте пустой шаблон через конструктор Excel-журнала.
2. После загрузки слева появится меню с разделами:
   - **Обзор** — главные числа группы, список тех, кому нужно внимание, распределение баллов и замечания к файлу.
   - **Студенты** — таблица группы с поиском и быстрыми фильтрами.
   - **Контрольные** — результаты контрольных работ.
   - **Диаграммы** — баллы и пропуски с подсветкой слабых результатов.
3. Карточка студента открывается двойным щелчком по строке (в «Диаграммах» — одним щелчком по столбцу). В ней есть «журнал» всех работ, где пропуск отмечен буквой «н», и переход к соседним студентам.
4. Карточку студента и диаграммы можно сохранить в PDF кнопкой «Экспорт в PDF».

Клавиши: `Ctrl+O` — открыть файл, `Ctrl+F` — поиск, `Enter` — открыть карточку, `Esc` — вернуться из карточки или очистить поиск.

Если загрузить файл неверного формата, программа покажет сообщение с причиной, а ранее загруженные данные останутся нетронутыми.

## Как заполнять Excel-файл

Проще всего создать шаблон встроенным конструктором: задайте число студентов, периодов, практических и лабораторных работ, и программа создаст файл с нужной структурой и готовыми формулами. Дальше остаётся вписать данные. Файл должен быть в формате `.xlsx` и содержать два обязательных листа с точными названиями (шаблон создаёт и третий лист, «Чек-лист», для программы он не нужен).

### Лист «Баллы, оценки» — журнал

| Строка / столбец | Что вписывать |
|---|---|
| Строка 1 | Названия столбцов: номер занятия, `оценка 1`, `ПР1_ур.5`, `ЛР 1_ур.9`, `ДЗ 1`, `Диф. зачет` и т. д. |
| Строка 2 | Дата занятия (формат даты Excel, например `07.09.2025`) |
| Со строки 3 | По одному студенту в строке |
| Столбец с ФИО | Заголовок должен содержать «ФИО» или «Фамилия» |
| Столбец `итог в баллах` | Итоговый балл. В шаблоне считается формулой |
| Столбец `кол-пропусков` | Число пропусков. В шаблоне считается формулой |

Как программа понимает данные:

- **Тип работы определяется по названию столбца:** `ПР1…` — практическая, `ЛР 1…` — лабораторная, название со словом «оценка» — оценка за период, со словом «зачёт» — зачёт, с «ДЗ» — домашнее задание. Столбец с номером занятия (`1`, `2`, `3`…) — обычный урок.
- **Пропуск — это пустая ячейка** в столбце урока, дата которого уже прошла. Поставили балл (даже 0) — студент присутствовал. Поэтому у пропустившего занятие ячейку нужно оставить пустой.
- **Баллы** вводятся числом, дробные можно через запятую или точку (`0,5`, `1.5`). Текст вроде `5-` программа сохранит, но как балл не посчитает, и покажет предупреждение после загрузки.
- **Служебные столбцы** (ФИО, итог, пропуски, «доп.задания») в работы не попадают.
- **Строки легенды и комментарии** под таблицей (например, «ОТЛИЧНО», «ХОРОШО») пропускаются автоматически. Строка считается студентом, только если у неё есть итоговый балл или число пропусков.
- **Опечатка в годе** (например, 2026 вместо 2025) исправляется автоматически, если исправленная дата попадает в семестр. О замене программа предупредит.

### Лист «Даты_темы» — расписание и темы

| Столбец | Что вписывать |
|---|---|
| B | Номер урока (тот же, что в заголовке журнала) |
| C | Дата занятия |
| D | Тема занятия |

Данные начинаются **со строки 5**. Если на занятие приходится несколько тем, остальные пишутся в следующих строках **без номера урока** — они присоединятся к теме предыдущего урока. Темы показываются в списке пропущенных занятий и в оценках студента.

### Советы

- Не переименовывайте листы «Баллы, оценки» и «Даты_темы» и не меняйте порядок строк 1 и 2.
- Перед загрузкой закройте файл в Excel: открытый файл программа прочитать не сможет.
- Формулы можно оставить как есть, но программа читает **сохранённые** значения: после заполнения шаблона обязательно сохраните файл в Excel (Ctrl+S), иначе итоговые баллы и пропуски останутся пустыми.
- Пример заполненного файла лежит в папке `utils/`.

## Технологии

- **Python** — основной язык программирования.
- **Tkinter** — создание графического интерфейса.
- **SQLite** — хранение данных.
- **Pandas** — обработка табличных данных.
- **Matplotlib** — построение графиков и визуализация.
- **OpenPyXL** — работа с Excel-файлами.
- **ReportLab** — формирование PDF-отчётов.
- **PyInstaller** — сборка приложения в исполняемый файл.
